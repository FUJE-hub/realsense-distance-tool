# RealSense 距离测量工具

基于 Intel RealSense D435i 深度相机的实时距离测量与三视图可视化工具。

## 核心功能
- 实时彩色、深度伪彩色、深度灰度三视图并行显示
- 鼠标点击任意位置实时测距
- 多窗口自动排列，避免重叠
- 多种退出方式，确保可靠退出

## 开发背景
这是我作为大一计算机专业学生完成的硬件交互练手项目。在开发时，我发现两个痛点并进行了针对性改进：
1.  **中文显示乱码**：OpenCV默认字体不支持中文，导致提示信息显示为“???”。
2.  **退出体验不佳**：程序常因窗口无响应而需强制终止。

## 关键技术决策
### 1. 字体与国际化
- **问题**：`cv2.putText` 默认使用 Hershey 字体，无法显示中文。
- **解决方案**：统一采用**英文界面**，并选用 `cv2.FONT_HERSHEY_DUPLEX` 粗体字，在保证清晰显示的同时彻底规避了字体兼容性问题。

### 2. 退出机制优化
- **问题**：官方示例通常只支持 ESC 键退出，一旦窗口失去焦点或卡顿便无法正常退出。
- **解决方案**：实现**四种退出方式**，确保任何情况下都能安全释放硬件资源：
  - 按 ESC 键
  - 按数字 2 键
  - 鼠标双击 RGB 窗口
  - 点击窗口关闭按钮
  - 控制台按 Ctrl+C

### 3. 可视化增强
- **原始方案**：官方示例通常只提供 RGB 和深度伪彩色两个视图。
- **改进**：新增**深度灰度视图**，便于更直观地观察深度数据的原始分布与对比度。

## 使用方法
1. 连接 Intel RealSense D435i 相机（推荐使用官方标配USB3.0数据线，以保证深度数据传输稳定不掉帧。）
2. 安装依赖：pip install pyrealsense2 opencv-python numpy
3. 运行程序：python realsense_camera.py
4. 在 RGB 窗口点击测距，支持上述四种方式退出。
